# CodeAlpha_social_media_platform
 # ✨ Vibe — Mini Social Media Platform A full-stack social media web application built with Node.js, Express, MongoDB, and Vanilla JavaScript. --- ## 🚀 Features | Feature | Description | |---|---| | 🔐 Auth | Register, login, JWT sessions, bcrypt password hashing | | 👤 Profiles | Edit name, bio, profile picture; view any user's profile | | 📝 Posts | Create, edit, delete posts with optional images | | ❤️ Likes | Like / unlike posts with animated heart | | 💬 Comments | Add/delete comments on posts | | 👥 Follow | Follow/unfollow users; personalized feed | | 🔔 Notifications | Get notified on likes, comments, follows | | 🔍 Search | Search users by name or username | | 🌐 Explore | Browse all posts (not just followed users) | | 📱 Responsive | Works on desktop, tablet, and mobile | | 🎓 Onboarding | Step-by-step guide for new users | --- ## 📁 Project Structure ``` vibe-social-media/ ├── server/ # Backend (Node.js + Express) │ ├── controllers/ │ │ ├── authController.js # Register, login, getMe │ │ ├── userController.js # Profile, follow, search, notifications │ │ ├── postController.js # CRUD posts, feed, likes │ │ └── commentController.js # CRUD comments │ ├── middleware/ │ │ ├── authMiddleware.js # JWT protect middleware │ │ └── uploadMiddleware.js # Multer image upload │ ├── models/ │ │ ├── User.js # User schema │ │ ├── Post.js # Post schema │ │ └── Comment.js # Comment schema │ ├── routes/ │ │ ├── authRoutes.js │ │ ├── userRoutes.js │ │ ├── postRoutes.js │ │ └── commentRoutes.js │ ├── uploads/ # Uploaded images (auto-created) │ ├── index.js # Entry point │ ├── package.json │ └── .env.example # Copy to .env │ ├── client/ # Frontend (HTML + CSS + Vanilla JS) │ ├── css/ │ │ └── style.css # Full responsive stylesheet │ ├── js/ │ │ ├── api.js # API helper, session, toast utils │ │ └── app.js # SPA router + all page controllers │ └── index.html # Main HTML shell │ ├── package.json # Root-level convenience scripts └── README.md ``` --- ## 🛠️ Setup Instructions ### Prerequisites - **Node.js** v16+ → https://nodejs.org - **MongoDB** (choose one): - **Local**: Install MongoDB Community → https://www.mongodb.com/try/download/community - **Cloud (Free)**: MongoDB Atlas → https://www.mongodb.com/atlas (recommended) --- ### Step 1 — Clone / Download the project ```bash # If downloaded as ZIP, extract it first cd vibe-social-media ``` --- ### Step 2 — Configure Environment Variables ```bash cd server cp .env.example .env ``` Open `server/.env` and fill in your values: ```env # MongoDB connection string # For local MongoDB: MONGO_URI=mongodb://localhost:27017/socialmedia # For MongoDB Atlas (cloud), it looks like: # MONGO_URI=mongodb+srv://username:password@cluster.mongodb.net/socialmedia # JWT Secret — change this to any long random string JWT_SECRET=change_this_to_something_very_secret_123 # Server port PORT=5000 # Your frontend URL (for CORS) CLIENT_URL=http://localhost:3000 ``` > **Getting a free MongoDB Atlas URI:** > 1. Go to https://www.mongodb.com/atlas > 2. Create a free account → New Project → Build a Database (Free tier M0) > 3. Create a user & whitelist your IP (or use 0.0.0.0/0 for dev) > 4. Click "Connect" → "Connect your application" → Copy the URI > 5. Replace `` with your actual database user password --- ### Step 3 — Install Server Dependencies ```bash cd server npm install ``` --- ### Step 4 — Start the Backend Server ```bash # In the server/ directory: npm start # Or for auto-restart on file changes (development): npm run dev ``` You should see: ``` ✅ MongoDB connected successfully 🚀 Server running on http://localhost:5000 📱 API ready at http://localhost:5000/api ``` --- ### Step 5 — Open the Frontend The frontend is pure HTML/CSS/JS — no build step needed! **Option A — Open directly in browser (simplest):** ```bash # Just open client/index.html in your browser # On Mac: open client/index.html # On Windows: start client/index.html ``` **Option B — Serve with a local server (recommended for no CORS issues):** ```bash cd client npx serve . -p 3000 # Then open http://localhost:3000 ``` **Option C — Use VS Code Live Server extension:** Right-click `client/index.html` → "Open with Live Server" --- ### Step 6 — Create Your Account & Start Vibing! 1. Open the app in your browser 2. Click **"Create Account"** and register 3. The onboarding guide will walk you through all features 4. Create a post, follow users, explore the feed! 🎉 --- ## 🌐 API Reference ### Auth | Method | Endpoint | Description | |--------|----------|-------------| | POST | `/api/auth/register` | Register new user | | POST | `/api/auth/login` | Login | | GET | `/api/auth/me` | Get current user (protected) | ### Users | Method | Endpoint | Description | |--------|----------|-------------| | GET | `/api/users/search?q=query` | Search users | | GET | `/api/users/:id` | Get user by ID | | GET | `/api/users/username/:username` | Get user by username | | PUT | `/api/users/profile` | Update profile (protected) | | POST | `/api/users/:id/follow` | Follow/unfollow user (protected) | | GET | `/api/users/notifications` | Get notifications (protected) | ### Posts | Method | Endpoint | Description | |--------|----------|-------------| | GET | `/api/posts/feed` | Get personalized feed (protected) | | GET | `/api/posts/explore` | Get all posts (protected) | | GET | `/api/posts/user/:userId` | Get user's posts | | GET | `/api/posts/:id` | Get single post | | POST | `/api/posts` | Create post (protected) | | PUT | `/api/posts/:id` | Edit post (protected, owner only) | | DELETE | `/api/posts/:id` | Delete post (protected, owner only) | | POST | `/api/posts/:id/like` | Toggle like (protected) | ### Comments | Method | Endpoint | Description | |--------|----------|-------------| | GET | `/api/comments/:postId` | Get all comments for a post | | POST | `/api/comments/:postId` | Add comment (protected) | | DELETE | `/api/comments/:id` | Delete comment (protected, owner only) | --- ## 🎨 Design Notes - **Theme**: Dark editorial with warm amber (`#f59e0b`) accent - **Fonts**: Playfair Display (headings) + DM Sans (body) - **Mobile**: Bottom navigation bar on small screens - **Animations**: CSS keyframes — fadeUp, shimmer, heartBurst --- ## 🔒 Security Notes For production deployment: - Change `JWT_SECRET` to a cryptographically random 64+ character string - Set `MONGO_URI` to your production Atlas cluster - Enable MongoDB Atlas network access restrictions - Use HTTPS (deploy on Render, Railway, Vercel + Railway, etc.) --- ## 🐛 Troubleshooting | Problem | Solution | |---------|----------| | `MongoDB connection failed` | Check your `MONGO_URI` in `.env`. Make sure MongoDB is running (local) or your IP is whitelisted (Atlas) | | `CORS error` in browser | Make sure `CLIENT_URL` in `.env` matches where you're serving the frontend | | Images not loading | Make sure the server is running on port 5000; uploads are served at `http://localhost:5000/uploads/` | | `Cannot find module` | Run `npm install` in the `server/` directory | | Port already in use | Change `PORT=5001` in `.env` and update `API_BASE` in `client/js/api.js` | --- ## 🧰 Tech Stack **Backend:** Node.js · Express.js · MongoDB · Mongoose · JWT · bcryptjs · Multer **Frontend:** HTML5 · CSS3 · Vanilla JavaScript (ES6+) · Fetch API --- Made with ❤️ — Happy Vibing! ✨ # Social_Media
